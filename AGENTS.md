# ХАҚ Platform — правила для агентов

Интерактивная платформа, раскрывающая «Концепцию продвижения ценностей Конституции» (ХАҚ — Халықтық Ата Заң Құндылықтары, Астана 2026).
Цель: каждая идея концепции подаётся через механику и визуализацию, которая привлекает внимание, побуждает изучать и удерживает взгляд.

## Перед началом работы (обязательно)
1. Прочитай `.agents/memory/conventions.md` — стек, стиль кода, дизайн-токены, API движка.
2. Прочитай `.agents/memory/decisions.md` — архитектурные решения (не пересматривай их без оркестратора).
3. Просмотри `.agents/memory/progress.md` — кто что уже сделал, чтобы не дублировать.
4. Если задача про контент — источник истины `source/pages/p{N}.txt` (N = страница PDF). Ничего не выдумывай.

## После завершения (обязательно)
- Допиши в `.agents/memory/progress.md` одну запись: `- [агент/роль] что сделано; файлы; открытые вопросы`.
- Если узнал что-то полезное для других агентов (грабли, неочевидное поведение) — допиши в `.agents/memory/lessons.md`.
- Не меняй `decisions.md` — предлагай изменения в своём отчёте оркестратору.

## Границы
- Трогай только файлы своей задачи. Движок `src/engine/*` и `src/content/types.ts` — зона оркестратора.
- Перед сдачей: `npm run typecheck` должен проходить для твоих файлов.
- Тексты концепции — дословно на русском/казахском; казахские буквы (Ә Ғ Қ Ң Ө Ұ Ү Һ І) не заменять.
- Не делай git commit/push — это делает оркестратор.
