# Глоссарий для казахской версии (обязателен для всех переводчиков)

Перевод — ЧЕРНОВОЙ, будет вычитан носителем. Цель: естественный литературный казахский (официально-деловой, но живой), без кальки.
Казахские термины, которые уже есть в оригинале (АДАМ, ӘДІЛДІК, ЗАҢ, ҚАМҚОРЛЫҚ, БІРЛІК, ОТАН, ДАУЫС, ӨРКЕНДЕУ, МҰРА, БЕЙБІТШІЛІК,
«Бұл ХАҚ па?», «Өз хақыңды біл. Өзгенің хақын құрметте.», пословицы, цитата Абая, жалақы/зейнетақы…) — переносить как есть.
Названия механизмов (ХАҚ Map, LifeХАҚ, ХАҚcheck, знак «Бұл ХАҚ», ХАҚ 4D, Open ХАҚ, ХАҚатон, ХАҚ hub, ХАҚеры, #БұлХАҚпа) — не переводить.
