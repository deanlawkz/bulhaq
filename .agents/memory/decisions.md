# Архитектурные решения (ведёт оркестратор)

- D1. Стек: Vite + TypeScript, без UI-фреймворка. DOM строится хелпером `h()` из `src/engine/dom.ts`. Анимации — GSAP 3 (+ScrollTrigger), плавный скролл — Lenis.
- D2. Контент — типизированные TS-модули в `src/content/` по контракту `src/content/types.ts` (`satisfies`), чтобы typecheck ловил ошибки извлечения.
- D3. SPA с hash-роутером (`#/`, `#/value/:id`, `#/mechanisms`, `#/play`, `#/profile`) — работает на любом статическом хостинге и в одном файле.
- D4. Две сборки: `dist/` (обычная, для GitHub Pages/любого статик-хостинга) и `dist-single/index.html` (всё инлайн — для публикации по одной ссылке).
- D5. Фирменный эффект — поле частиц на WebGL (`src/engine/field.ts`), которое собирается в логотип/иконку ценности и реагирует на курсор. Это общий фон всех страниц.
- D6. Каждая секция — модуль `src/sections/*.ts` с функцией `mount(root, ...) => Cleanup`. Страницы в `src/pages/*` собирают секции.
- D7. Цвета ценностей — по градиенту бренда (бирюзовый → синий → фиолетовый), см. `src/engine/theme.ts`.
- D8. Уважаем `prefers-reduced-motion`: все анимации через `motion.ts`, который их упрощает.
- D9. Новый репозиторий создать нельзя (403 у интеграции) — проект живёт в `course-studio/hak/`.
- D10. v2 «Хартия Степи»: отказ от лендинговой стилистики (капсулы, стекло, градиенты, Unbounded). Антиква + золото/небесно-голубой флага + казахский орнамент. См. design.md.
