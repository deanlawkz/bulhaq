# Арт-дирекшн «Хартия Степи» (v3) — ОБЯЗАТЕЛЕН для всех секций

## v3 — правки заказчика к v2 (приоритет над всем ниже)
- Антиква (Noto Serif Display) отклонена: «слишком книжная, как старые документы и сайты 90-х». Нужен СОВРЕМЕННЫЙ гротеск без маркетингового нейрослопа.
  → Единственный шрифт: Commissioner (`--f-display` = `--f-text` = `--f-mono`). Заголовки — веса 300–400, плотный трекинг (−0.02…−0.035em). Текст 400, интерфейс 500.
- Мелкие подписи сверху («ЦЕННОСТЬ 02 / 10 · ИЗМЕРЕНИЕ ПРАВИЛ» моно-капсом с разрядкой) отклонены: «мелко, плохо видно, ИИ-нейрослоповый стиль».
  → Подписи/eyebrow: обычный регистр (не капс), без разрядки, 14–16px, вес 500, цвет gold. Числа — `font-variant-numeric: tabular-nums`. НИКАКИХ `text-transform: uppercase` + `letter-spacing > 0.04em`. Минимальный размер любого текста — 13px.
- Курсива больше нет (у шрифта его нет; `font-synthesis: none`). Акцент — цветом (gold/accent) или весом, не наклоном.
- Солнце как символ заменить на шаңырақ «как на гербе Казахстана» — `illustration('shanyrak')` перерисован оркестратором.


Отзыв заказчика на v1: «примитивный лендинг», «шрифт маркетинговый, не строгий», «плашки — ИИ-шный стиль»,
«вместо стран с флагами и иллюстрациями тупо плашки под слова», «топорная угловатая примитивная схема» (о шестиугольнике принципов).
Удачным признаны: поле частиц, логотип ХАҚ из частиц, реакция частиц на курсор. Их сохраняем.

## Идея
Конституция — это ДОКУМЕНТ и культурный код, а не продукт. Платформа выглядит как изданная хартия:
ночная степь, золото солнца и небесно-голубой цвет флага Казахстана, казахский орнамент (қошқар мүйіз — бараньи рога),
шаңырақ, тонкие золотые линейки, строгая антиква, номера статей моноширинным шрифтом. Сдержанно, дорого, торжественно.

## Типографика v2 (УСТАРЕЛО, см. v3 выше)
- `--f-display` Noto Serif Display — заголовки, цитаты, крупные числа, казахские слова. Веса 300–450 (НЕ жирный). Курсив — для казахских строк и акцентов.
- `--f-text` Golos Text — основной текст, интерфейс.
- `--f-mono` IBM Plex Mono — статьи («ст. 1, 12–25»), страницы («с. 15»), счётчики, eyebrow-подписи.
- Разделы документа нумеруем как в концепции: римские I, II, III и подразделы 01–06 (это правда о структуре PDF).

## Палитра (токены в base.css)
`--night` фон, `--ivory` текст, `--gold`/`--gold-2` орнамент/акцент, `--sky` флаг/интерактив, `--rule` золотая линейка, `--rule-2` тонкая светлая.
`--accent` — цвет текущей ценности на её странице. Цвета ценностей — `valueMeta(id).color` (приглушённые).

## ЗАПРЕЩЕНО (это и есть «ИИ-шный стиль»)
- Капсулы/«таблетки» (border-radius 999px), скругления > 3px у блоков, стеклянные карточки с blur, неоновое свечение (box-shadow 0 0 40px цвет).
- Градиентный текст, радужные/фиолетово-синие градиенты, «аврора»-пятна внутри секций, конические радужные фоны.
- Сетки одинаковых карточек «заголовок + 2 строки» как основной приём. Номера-призраки 01/02 огромным полупрозрачным шрифтом.
- Схемы из прямых палок между кнопками-таблетками. Иконки в цветных квадратах.
- Хардкод старых цветов: #2f5bff, #7b2ff7, #2bb3a3, #2f8bff, #6a5cff, фиолетовые/розовые неоны. Только токены и `valueMeta`.

## ДЕЛАЕМ
- Композиция как в книге/хартии: большие поля, колонки, линейки `--rule`, выносные цитаты, маргиналии со ссылками на статьи/страницы (`.ref`).
- Схемы и диаграммы — тонкая графика: 1px золото/слоновая кость, дуги и окружности вместо ломаных, орнамент, засечные цифры. Узлы — медальоны (кольцо 1px) или просто подписи у точки, не плашки.
- Иллюстрации — линейная графика из `src/engine/ornament.ts`, прорисовка штрихом `drawOn(svg)`:
  `ornamentBand(n)`, `ramHorn()`, `rosette()`, `flagKZ()`, `flagDK()`, `flagSE()`,
  `illustration('shanyrak' | 'book' | 'scales' | 'candle' | 'measure' | 'sun' | 'yurt' | 'sprout')`.
  Нужна своя иллюстрация — нарисуй в `src/sections/<секция>-art.ts` в том же стиле (viewBox 0 0 200 160, stroke currentColor 1.6, `vector-effect="non-scaling-stroke"`, fill none). Используй `ramHornPath()` для орнамента.
- Метафоры из мира предмета: шаңырақ (венец юрты держится на уықах — «опоры»), юрта/кереге (единство), весы (справедливость), раскрытая книга (Конституция), солнце флага, орнаментальная лента как разделитель разделов.
- Движение — сдержанное и осмысленное: прорисовка линий, медленные проявления, параллакс. Одна выразительная анимация на секцию лучше пяти.
- Медальон ценности: `.icon-badge` (кольцо в цвете ценности).
- Вкладки/переключатели: `.chip` теперь строгая вкладка с подчёркиванием (не капсула) — `aria-selected`/`aria-pressed` подсвечивают.
- Кнопки: `.btn` (рамка), `.btn--primary` (золото). Без скруглений.
- Панели: `.glass` теперь плоская панель документа (без blur). Используй экономно — не всё должно быть в рамке.
