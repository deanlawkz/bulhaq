# ХАҚ — Халықтық Ата Заң Құндылықтары

Интерактивная платформа, раскрывающая «Концепцию продвижения ценностей Конституции» (Астана, 2026):
каждая идея концепции подана через механику и визуализацию.

## Что внутри
- **Главная** (`#/`) — частицы собираются в логотип; преамбула; дерево слова «хақ» и формула «Өз хақыңды біл. Өзгенің хақын құрметте.»;
  интерактивные весы общественного договора и путь ценности; созвездие 10 ценностей (система / пять пар / основа — Конституция);
  пять измерений и образ страны; «Бұл ХАҚ па?» как общий критерий; от ценности к культурной норме.
- **Ценность** (`#/value/:id`) — иконка из частиц, пословица и формула, вопрос «Бұл ХАҚ па?», смысл и образ страны,
  карта статей Конституции, четыре аудитории с интерактивным ХАҚ-тестом, колода сцен LifeХАҚ.
- **Механизмы** (`#/mechanisms`) — кампания vs норма, шесть принципов, прямое и средовое продвижение.
- **Игра** (`#/play`) — «Узнай ценность» по реальным сценам LifeХАҚ.
- **Мой ХАҚ** (`#/profile`) — радар по 10 ценностям из ответов ХАҚ-теста (хранится только в браузере).

## Разработка
```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — статический сайт для любого хостинга
npm run build:single   # dist-single/index.html — один самодостаточный файл
```
Публикация: каждый push в `main` собирается GitHub Actions (`.github/workflows/deploy.yml`) и выкладывается на GitHub Pages → **https://bulhaq.kz** (файл `public/CNAME`).
DNS: A `@` → 185.199.108.153 / 109.153 / 110.153 / 111.153, CNAME `www` → deanlawkz.github.io.

## Как устроена разработка
Проект строился командой агентов под управлением оркестратора. Правила — `AGENTS.md`, общая память — `.agents/memory/`
(конвенции, архитектурные решения, журнал прогресса, уроки). Контент извлечён дословно из PDF (`source/pages/p{N}.txt`)
в типизированные модули `src/content/` по контракту `src/content/types.ts`.
